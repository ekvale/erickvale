How to catalog a publication

  • Required: title, description (150+ characters), document type, publication date, language, at least one topic tag, and either a source URL or a file (or both).
  • Recommended: translated-document checkbox when the file is a translation; additional tags for population, geography, and program.
  • Topic vs language: tag what the document is about. Set Publication language for the language of the file. A TB fact sheet translated into Hmong is tagged Tuberculosis, language Hmong — not a Hmong ethnicity tag unless the content is about that community.
  • Source URL vs file: the URL is the canonical public page (for example on health.mn.gov). The file is the document people download from this library. Provide whichever you have; both is fine when MDH hosts a copy of an external page.
  • File naming (NNLM): no spaces or special characters; prefer YYYY-MM-DD_short-title_language_v1.pdf. See NNLM file naming conventions.
  • Prefer MDH glossary wording for tags: MDH public health glossary.
