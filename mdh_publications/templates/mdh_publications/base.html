{% load static %} {% comment %} Standalone base for the MDH Publications Library. These templates were authored against Bootstrap 4 (form-row, form-group, badge-secondary, mr-/ml- spacing, and a data-ride carousel on the landing page). The site-wide base_site.html loads Tailwind only, so none of those classes resolved and every page rendered without cards, grid, or buttons. Bootstrap 4 and Tailwind cannot share a page: both ship a global reset, so loading Bootstrap into base_site.html would restyle the site nav and footer. Instead this app gets its own shell, the same approach allminnesota already uses. Bootstrap 4.6 specifically -- not 5 -- because the class names above were renamed in 5 and the markup would still be wrong. Blocks match base_site.html (title / extra_head / content) so the twenty page templates only had to change which base they extend. The content wrapper keeps id="main-content" and .container because publication_landing overrides "#main-content.container" to go full width behind its hero. {% endcomment %} {% block title %}MDH Publications Library{% endblock %} {# Internal library; keep it out of search results. #} {% block extra_head %}{% endblock %} {% comment %} mdh-app is required: publication_landing scopes its white-on-dark hero rules to body.mdh-app. Without it the hero headings, tagline and CTA links fall back to dark navy on a dark navy overlay.
